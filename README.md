## Sobre o Projeto

**Futenautas** é uma aplicação desenvolvida como parte de um trabalho prático da disciplina de Banco de Dados. Inspirado no famoso game **Cartola FC**, o projeto tem como objetivo proporcionar uma experiência divertida e competitiva para os usuários, permitindo a criação de times virtuais compostos por jogadores reais da Série A do Campeonato Brasileiro.

## Funcionalidades

- 🏟️ **Criação de Times**: O usuário pode montar seu próprio time virtual.
- ⚽ **Escalação de Jogadores**: Selecione jogadores reais para formar a escalação do seu time a cada rodada.
- ✨ **Pontuação por Rodada**: Acompanhe o desempenho dos jogadores com pontuações atualizadas por rodada.
- 🔍 **Filtros Inteligentes**: Filtre jogadores por posição, nome ou clube.
- 🏆 **Ranking de Times (Clubes)**: Veja o ranking dos clubes reais com base na soma da pontuação de seus jogadores.
- 📊 **Classificação dos Times de Usuários**: Um ranking geral para deixar a competição ainda mais empolgante!

## Tecnologias Utilizadas

- Frontend: Blade
- Backend: PHP com Laravel
- Banco de Dados: MySQL
